## 代表プロジェクト

### [台北市YouBikeネットワーク・道路リスク分析](https://github.com/kuku0508/YouBike-Road-Risk-Analysis)

大規模なYouBike利用データ、道路レベルの自転車通行量推定、交通事故データを組み合わせた、再現可能な分析プロジェクトです。

- **109,713,899件**の解析済み利用記録からデータ処理パイプラインを構築
- **2,782か所のステーション**と**1,125,519本の有向エッジ**からなるODネットワークを構築
- **1,100,919本のBRouter経路**を再構築し、道路マイクロセグメント単位の自転車通行量を推定
- **46,586件の事故エンティティ**を再構築し、**39,711件**を道路マイクロセグメントへ正式に対応付け
- ネットワーク分析、クラスタリング、地理空間マッチング、データ品質検証、自動テストを実施
- 分析上の仮定、除外状態、研究上の制約、再現性に関する判断を記録

このプロジェクトの目的は、追加調査が必要な道路環境をデータによって絞り込むことです。「台北で最も危険な道路」のランキングを断定するものではありません。

🌐 [ポートフォリオでプロジェクトを見る](https://kuku0508.github.io/projects/youbike_sna/)

## スキル・使用技術

- **プログラミング・データ処理：** Python、R、SQL、Pandas、NumPy、PyArrow、SQLite
- **統計分析：** 回帰分析、クラスタリング、生存時間分析、モデル診断
- **ネットワーク分析：** NetworkX、igraph、中心性指標、Louvain法
- **地理空間分析：** Shapely、PyProj、Folium、Leaflet、BRouter
- **データ可視化：** Matplotlib、ggplot2、インタラクティブマップ
- **分析ワークフロー：** データクリーニング、データ品質検証、Git、自動テスト、再現可能な分析

## 分析で大切にしていること

最終的なグラフやモデルを作るだけではなく、次の点を大切にしています。

- **追跡可能性：** 重要な仮定、データ変換、分析上の判断を記録する
- **再現可能性：** コード、設定、検証記録、必要なデータフィンガープリントを残す
- **解釈可能性：** 結果の実務的な意味と限界をあわせて説明する
- **不確実性への配慮：** 確認された事実、妥当な推論、未確認の事項を区別する
